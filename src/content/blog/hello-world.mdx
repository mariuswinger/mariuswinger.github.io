Welcome! This site is built with [Astro](https://astro.build), React and Tailwind CSS, and is
deployed to GitHub Pages.

## Why Astro?

- Static by default — pages ship zero JavaScript unless they need it.
- Islands let me drop in React only where interactivity matters.
- Content collections give type-safe Markdown/MDX for posts like this one.

```ts
const greeting: string = 'Hello, world';
console.log(greeting);
```
